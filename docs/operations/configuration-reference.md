# Configuration reference

All settings are environment variables with the prefix `JOBS_RADAR_`, read from the process
environment or the untracked `.env` file at the repository root (`./jobs-radar.sh --init-env`
creates it with random secrets). Real environment variables win over `.env`. An unknown
`JOBS_RADAR_*` name stops the start-up, so typos fail loudly. `make config-check` reports exposure
and secret mistakes without printing a secret. Defaults below are the application defaults;
`.env.example` shows the values the launcher writes.

| Variable | Default | Meaning |
|---|---|---|
| `JOBS_RADAR_ENV` | `dev` | `dev`, `test` or `prod`. `test` refuses a database whose name does not end in `_test`. |
| `JOBS_RADAR_LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING` or `ERROR`. Logs never contain secrets, prompts, CV text or job descriptions. |
| `JOBS_RADAR_API_BIND` | `127.0.0.1` | Address the API port is published on. `0.0.0.0` exposes the API (no authentication) to the network. |
| `JOBS_RADAR_API_PORT` | `8100` | API port on the host. |
| `JOBS_RADAR_FRONTEND_PORT` | `5180` | Vite dev server port. |
| `JOBS_RADAR_CORS_ORIGINS` | `["http://127.0.0.1:5180"]` | JSON list of origins the API accepts. Never `*`. |
| `JOBS_RADAR_FRONTEND_ALLOWED_HOSTS` | `localhost,127.0.0.1` | Host names the Vite dev server accepts; add this machine's name to open the UI from another computer. |
| `JOBS_RADAR_DB_HOST` | `127.0.0.1` | Database host seen by processes on the host (containers use the Compose network). |
| `JOBS_RADAR_DB_PORT` | `5440` | Database port on the host. |
| `JOBS_RADAR_DB_BIND` | `127.0.0.1` | Address the database port is published on. Prefer loopback; use an SSH tunnel for remote tools. |
| `JOBS_RADAR_DB_NAME` | `jobs_radar` | Database name. |
| `JOBS_RADAR_DB_USER` | `jobs_radar` | Database role. |
| `JOBS_RADAR_DB_PASSWORD` | none (required) | Database password; generated by `--init-env`. |
| `JOBS_RADAR_CREDENTIAL_KEY` | none | Fernet key that encrypts stored credentials (AI keys, GitHub token). Back it up **separately** from database backups; without it stored credentials cannot be read and must be entered again. |
| `JOBS_RADAR_OLLAMA_URL` | `http://host.docker.internal:11434` | The one local model server that may be used. |
| `JOBS_RADAR_ALLOW_LOCAL_PROVIDERS` | `false` | Allow connecting to a local model server (Ollama). |
| `JOBS_RADAR_EXTRACTION_ENABLED` | `false` | Seeds the first local AI connection once; afterwards the AI & privacy screen decides (ADR-046). |
| `JOBS_RADAR_EXTRACTION_MODEL` | `qwen3:8b` | Model for the seeded connection. |
| `JOBS_RADAR_EMBEDDING_MODEL` | `qwen3-embedding:8b` | Embedding model used to compare descriptions. |
| `JOBS_RADAR_EXTRACTION_MAX_CHARS` | `12000` | Longest description sent to the model; longer text is truncated and flagged. |
| `JOBS_RADAR_OLLAMA_TIMEOUT_SECONDS` | `180` | Seconds one local-model call may take. |
| `JOBS_RADAR_WORKER_POLL_SECONDS` | `15` | How often the worker looks for work. |
| `JOBS_RADAR_EXTRACTION_CONCURRENCY` | `1` | Extractions sent to the model at once (ADR-077). Raise it (for example 3) together with `OLLAMA_NUM_PARALLEL` on the Ollama server; with a server that handles one request at a time it only queues them. |
| `JOBS_RADAR_WORKER_HEARTBEAT_MAX_AGE_SECONDS` | `90` | The API reports the worker as stale after this many seconds without a heartbeat. |
| `JOBS_RADAR_MCP_ENABLED` | `false` | Master switch of the MCP server for AI agents (ADR-078). Only the word `true` turns it on; anything else, or no value, and the server refuses to start. See [mcp-server.md](mcp-server.md). The API ignores it; it is declared so the shared `.env` is accepted. |
| `JOBS_RADAR_MCP_ALLOW_WRITES` | `false` | Also register the MCP tools that change the inbox (shortlist, ignore, archive...) and queue collections. Needs `JOBS_RADAR_MCP_ENABLED=true`. |
| `JOBS_RADAR_MCP_API_URL` | `http://127.0.0.1:<API port>` | Where the MCP server finds the API (http or https, no credentials in the URL). |
| `JOBS_RADAR_MCP_TIMEOUT_SECONDS` | `15` | Seconds the MCP server waits for one API answer (up to 120). |

Settings stored in the database (not environment): the daily schedule, the AI connections and
their credentials, the privacy policy, sources and their rate limits (Sources and AI & privacy
screens).

Optional variables for the opt-in smoke tests (`make smoke`): `JOBS_RADAR_SMOKE_OLLAMA_URL`,
`JOBS_RADAR_SMOKE_MODEL`, `JOBS_RADAR_SMOKE_API_URL`, `JOBS_RADAR_SMOKE_API_KEY`.
